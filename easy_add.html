📝 How to Use

  1. Fill in the person's name (first and last name required)
  2. Optionally select parents and/or children from existing family members
  3. Click "Save Person" to download the JSON file
  4. Add the downloaded file to the generated_people/ folder in the repository
  5. Push to GitHub - the person will be automatically integrated!
✓ Person saved successfully! Download should start automatically.
